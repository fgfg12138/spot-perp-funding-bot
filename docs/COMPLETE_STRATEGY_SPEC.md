# 现货-永续资金费率套利策略 · 完整规格书

> **策略类型**: Delta 中性资金费率套利  
> **核心逻辑**: 买入现货 ✅ + 做空同等名义永续合约 ✅ = 对冲价格风险 ✅，只赚资金费  
> **单笔收益公式**: 入场基差 + 资金费收入 - 出场基差 - 手续费 - 滑点 - 风险折价  
> **代码路径**: `lib/strategy-v121/`

| ≤ 0.01% | 8 分 | 一般 |

## 四、收益计算（净收益模型）

### 净收益公式

```
净收益 = 入场基差 - 出场基差 + 资金费(衰减后) - 手续费 - 滑点 - 风险折价
```

### 资金费衰减

| 距下次资金费 | 第 1 次衰减率 | 第 2 次 | 第 3+ 次 |
|------------|-------------|--------|---------|
| < 30 分钟 | 100% | 50% | 1% |
| 30-120 分钟 | 80% | 50% | 1% |
| 120-240 分钟 | 60% | 50% | 1% |
| > 240 分钟 | 40% | 50% | 1% |

### 手续费

| 场景 | 费率 |
|------|------|
| Maker | 0.02% × 4 条腿 |
| Taker | 0.07% × 4 条腿 |

### 风险折价

| 路径类型 | 折价 |
|---------|------|
| 同所 Binance/OKX | 0.05% |
| 同所 HTX | 0.15% |
| 跨所 Binance↔OKX | 0.15% |
| 含 HTX 跨所 | 0.25% |

### 最小收益要求

| 阶段 | 最小净收益率 | 最小利润 |
|------|------------|---------|
| **MAINNET_TINY** | 0.40% (B/B), 0.50% (跨), 0.60% (含HTX) | **$5** |
| **CONTROLLED_LIVE** | 同上 | **$10** |
| **MATURE** | 同上 | **$20** |

### 分批下单

```
第 1 批: 30% — 试探性进场
```

| 偏差范围 | 状态 |
|---------|------|

## 七、风控体系（4 层）

### 第 1 层 — Kill Switch（全局开关）

| 状态 | 含义 |
|------|------|
| OFF | 全部放行 |
| READ_ONLY_ONLY | 只读，不下单 |
| PAUSE_NEW_ENTRIES | 不准开新仓，可平仓/风控 |
| PAUSE_ALL_AUTOMATION | 全部自动化停止 |

### 第 2 层 — 执行前安检门（SafeExecutionOrchestrator）

```
下单申请 → 
  ① 交易所检查 (仅 binance/okx) →
  ② realTradeEligible 检查 →
  ③ 模拟候选阻挡 →
  ④ OrderConstraintPrecheck (下单限制预检) →
  ⑤ CapitalPrecheck (资金预检) →
  ⑥ TransferRequired (如需划转) →
  → HUMAN_APPROVAL_REQUIRED (等待人工批准，不下真实单)
```

### 第 3 层 — 风控仲裁器

仲裁顺序（高优先级先执行）：

```
┌─ 仓位偏差 ≥5%      → 事故级别
├─ 硬止损触发        → 全部退出
├─ 回撤 ≥10%         → 全部退出
├─ 回撤 8-10%        → 减仓
├─ 回撤 5-8%         → 减仓
├─ 回撤 3-5%         → 减仓警告
├─ ADL 高风险        → 全部退出
├─ ADL 中高风险      → 减仓 30-50%
├─ ADL 中等          → 禁止加仓
├─ 深度下降 ≥70%     → 退出
├─ 深度下降 ≥50%     → 减仓
├─ 价差扩大 ≥3倍     → 减仓/退出
├─ 价差扩大 ≥2倍     → 禁止加仓
├─ 仓位偏差 1-3%     → 修复
└─ 一切正常           → 不做操作
```

### 第 4 层 — 持仓监控

- 强平距离监控 — 分 BTC/ETH vs 山寨币不同阈值
- 连续资金费下降报警
- 冷却期自动跳过
