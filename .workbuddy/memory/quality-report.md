### 2.3 环境问题分析（已修复）

之前失败的 `sqliteRepositoryBoolMapping` 测试（9 个）是由于 `better-sqlite3` 原生模块编译时 Node.js 版本（v24, 模块版本 137）与运行时 Vitest 使用的 Node.js 版本（v22, 模块版本 127）不匹配导致。

**修复**：执行 `npm rebuild better-sqlite3` 后，9 个测试全部通过。
